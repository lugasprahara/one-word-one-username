One word, and the word is a name: **lugasprahara**, the entrant's own make.fun username, sent bare — no explanation, no links, no pitch, exactly as the bounty asks. The program in `main.ts` writes that single handle to `/output/entry.txt`, checking first that it is one word of 1–30 characters with nothing tacked on, and that one word is the whole entry.

## Run it

```sh
node main.ts
```
